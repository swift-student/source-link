01 / Trace a call

A stack you can step into.

02 / Follow the flow

One link. Your local code.

This is the successful path for a Swift symbol link. Each step links to the code responsible for it.

01–02

Portable names, personal paths.

The link names a repository and a file. Source Link maps that repository to the folder you chose, so nobody needs your absolute path.

03

A declaration, not a line number.

For Swift, ?symbol= finds a declaration in the current file without building or indexing. Line changes are fine; renames and file moves need updated links.

If several declarations match, you choose one. If none match, Source Link reports an error.

04–05

Continue in your editor.

Your editor profile turns the file and position into a command. Xcode, VS Code, Cursor, Zed, and other editors are supported.

03 / Make your own

A URL with a destination.

Use a line link for any text file, or a symbol link for a Swift declaration.

source-link://source-link/README.md?line=1↗

Repository alias
source-link maps to your checkout.

Relative file path
README.md lives inside that folder.

Position or symbol
?line=1 opens the first line.

In D2, add a link to a node. Render to SVG and embed it inline on a web page to keep the links active.

resolve: "Resolve the file" {
  link: "source-link://source-link/Packages/SourceLinkPackage/Sources/SourceLinkCore/SourceLink.swift?symbol=SourceLink.resolve%28root%3A%29"
}

GitHub and Slack can show static previews. Share this page when you want readers to click through to source.

Try it on your Mac

Connect your checkout once.

  1. Build and open Source Link. Requires macOS 15+; follow the build instructions. The first Homebrew release is still forthcoming.
  2. Keep a local checkout of this repository. The diagrams above open files from swift-student/source-link.
  3. Open the README in your editor ↗ Allow your browser to open Source Link. On first use, choose your repository folder and editor.

Then click any stack frame or flow step above. Each reader uses their own mapping for the source-link alias.
